# Description

Swirl Remake is a portfolio website inspired by the original Swirl project. I redesigned and rebuilded in my own way as the part of Hackclub Cont.d programme.

Also this shows my web development projects, game development projects and many other things

# Features

- First page with an smooth transition
- A cool animation when clicking the enter button
- hamburger menu for the navigation in the mobile
- have scroll reveal animation
- about section, ofcourse, its about me
- skill section showing my skills
- next is project section showing my web and game  projects
- responsive website

# How to try this

-It's very simple, go to this link: https://swirl-remake.vercel.app/

# Tech stack of orignial Swirl

- HTML
- CSS

# Tech stack of Swirl Remake

- React
- Tailwind CSS
- Vite

# Make this Swirl Remake yours

- Clone this repository
- Go to the folder(most probably git will make a folder with the name of the project)
- install dependencies using git install
- npm run dev
- go to this url : http://localhost:5173/

Congrats!, you hosted it locally
